# AWS Control Tower

- easy way to setup and govern a secure and compliant multi-account AWS environment
- AWS control tower uses AWS organizations to create accounts

- Benefits
  - automate the set up of your environment in a few clicks
  - automate ongoing policy management using guardrails
  - detect policy violations and remediate them
  - monitor compliance through interactive dashboard

## Guardrails

- Provides ongoing governance for your control tower environment [AWS accounts]
- Preventive guardrail: using SCPs
  - ex: restrict regions across all your accounts
- Detective guardrail: using AWS config
  - ex: identify untagged resources
