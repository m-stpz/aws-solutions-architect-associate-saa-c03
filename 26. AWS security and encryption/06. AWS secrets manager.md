# AWS Secrets Manager

- similar to ssm parameter store, as it's meant for storing secrets
  - however, it differs on the fact that AWS secrets manager allows to FORCE ROTATION OF SECRETS on given time

- scheduled or automatic password rotation?
  - secrets manager

- lowest cost and doesn't require rotation?
  - ssm parameter store

- other differences
  - automate generation of secrets on rotation [uses lambda]
  - integration with RDS [mysql, postgresql, aurora]
  - secrets are encrypted using KMS
