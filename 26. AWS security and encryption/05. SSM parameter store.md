# SSM Parameter Store

- Secure storage for configuration and secrets
  - System Manager [SSM]
  - serverless, hierarchical key-value storage service
    - hierarchical: like a file system, what allows granting IAM permissions to entire path at once

  ```
  /my-department/
    my-app/
        dev/
            db-url
            db-password
        prod/
            db-url
            db-password
    other-app/
  /other-department
  ```

  - centrally stores config data and secrets
  - separates config from application code

- Secure storage config and secrets
- optional seamless encryption using KMS
- serverless, scalable, durable, easy SDK
- version tracking of configs / secrets
- security through IAM
- notifications with EventBridge
- integration with CloudFormation

```
            encrypted                       decryption
            config                          service
applications -----------> SSM parameter store --------> AWS KMS
            <-----------            |
            plaintext config        |
                            check IAM permissions
```
