# CloudHSM

- KMS: AWS manages the software for encryption
- CloudHSM: AWS provisions encryption hardward
  - dedicated hardware
  - HSM: hardware security module
- Manage your own encryption keys entirely, not AWS
- HSM is tamper resistant, FIPS 140-2 level 3 compliance
- supports symmetric and asymmetric encryption [SSL/TLS keys]
- no free tier
- most use the CloudHSM client software
- Redshift supports CloudHSM for db encryption and key management
- Good option to use with SSE-C encryption
